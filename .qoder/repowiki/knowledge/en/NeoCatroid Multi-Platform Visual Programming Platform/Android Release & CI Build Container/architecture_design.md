Two cooperating artifacts:
- `fastlane/Fastfile` defines the release surface as one Ruby lane per Catroid variant (Catroid, CreateAtSchool, EmbroideryDesigner, Luna&Cat, Phiro, PocketCodeBeta, Mindstorms), each offering three operations — upload metadata only (`upload_Metadata_*`), upload signed APK to the alpha track (`upload_APK_*`), and promote from alpha to production (`promote_*`). All lanes call `upload_to_play_store` with `json_key_data` sourced from the `googlePlayJsonKey` environment variable and expect pre-built APKs under `catroid/build/outputs/apk/<variant>/signedRelease/...`.
- `fastlane/Appfile` pins the default package name for fastlane's supply plugin.
- `docker/Dockerfile.jenkins` builds an immutable Debian Bullseye container used by Jenkins: installs OpenJDK 17, Ruby + fastlane via gem, Android SDK command-line tools plus build-tools/platforms/NDK/CMake/system-images, creates a non-root `user` (uid/gid passed in) with KVM group membership, and accepts SDK licenses. The container is the single execution environment for both Gradle builds and Fastlane uploads.
Dependency direction is one-way: the Docker image provides the runtime; the Fastfile consumes it. No code is built inside this module — it orchestrates external artifacts produced by the repo's Gradle build.
