Training is driven by Windows batch wrappers rather than Makefiles: `run_training.bat` invokes `train_transformer.py` (or `train_lstm.py`); `prepare_colab.bat` bundles assets into `colab_pack.zip` for the Colab notebooks; `deploy.bat` copies artifacts into the Android app tree. The default project source directory is `datasets/` and the intermediate JSON is written to `training_data/projects.json` unless overridden via `--json`.
