The root is a Gradle multi-project that wires together several independently built artifacts around a single shared contract: `core_library` exposes the `RuntimeServices` interface (audio, network, notification, text) which both `catroid_android_app` (Android) and `desktop_runtime` (LWJGL3/Windows) implement. The Kotlin/KSP-based `lunoscript_tooling` (`lunoscript-annotations` + `lunoscript-processor`) generates a native-function registry consumed by the interpreter in the Android app. `vnc_client` is an Android library included as a dependency of the app for remote framebuffer streaming. Non-Gradle children — `ai_code_suggestion` (Python), `automation_and_build_scripts`, and `ci_and_release_assets` (Fastlane/Jenkins Docker) — are standalone tools invoked from the root's Jenkinsfile variants (`Jenkinsfile`, `Jenkinsfile.BuildStandalone`, `Jenkinsfile.ManualTests`, `Jenkinsfile.OutgoingNetworkCallsTests`, `Jenkinsfile.SensorboxTests`, `Jenkinsfile.releaseAPK`) to build flavors, sign APKs, and publish to Google Play alpha/production. Version and dependency versions (Kotlin 2.0.21, AGP 8.7.3, Koin 2.1.6, Lifecycle 2.8.7) are centralized in the root `build.gradle` `ext` block so every child reuses the same stack.
