Before building, ensure `google-services-template.json` exists at the module root (the build copies it into `src/danvex/` and `src/runtime/` automatically); otherwise Google Services tasks will fail. Release signing requires passing `-PsigningKeystore=... -PsigningKeystorePassword=... -PsigningKeyAlias=... -PsigningKeyPassword=...` on the command line. The `standalone` flavor can be rebranded with `-PpackageName=<suffix>` instead of the default `.standalone` suffix. Unit tests need `--add-opens` flags for JDK 17+ PowerMock compatibility, already applied in `testOptions.jvmArgs`.
