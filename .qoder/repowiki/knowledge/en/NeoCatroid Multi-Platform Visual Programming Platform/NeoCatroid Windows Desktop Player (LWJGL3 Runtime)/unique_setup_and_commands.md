`build_exe.bat` is the single end-to-end builder: it locates `gradlew.bat` upward from the repo root, builds `player.jar`, creates a `jlink`-based minimal JRE under `build/win-dist/bundle/jre`, runs the detached `:post` child to wrap with Launch4j, embeds an optional `project.zip` as a NEOCAT01 footer, and stages the deliverable. Requires a JDK on PATH (for `jlink`) and optionally ImageMagick or .NET `System.Drawing` to convert `icon.png` → `icon.ico`.
