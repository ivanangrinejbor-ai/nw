Pure-JVM Gradle module (`:desktop-runtime`) depending only on `:core` for portable contracts. The entry point is `DesktopStage.main`, which registers desktop implementations of every seam interface via singleton holders (`RuntimeServicesHolder`, `AudioServiceHolder`, `MidiServiceHolder`, `TextServiceHolder`, `NotificationServiceHolder`, `NetworkServiceHolder`) before launching a `Lwjgl3Application` with `DesktopStageListener` as its `ApplicationAdapter`. `DesktopStageListener` owns the LWJGL render loop, camera, physics world, script engine/runner, and input — mirroring Android's `StageActivity` but without any Android dependency. Service implementations live in sibling packages (`audio`, `network`, `notification`, `text`, `runtime`) each providing one class per interface. The build produces a fat JAR named `player.jar` whose manifest points at `org.catrobat.catroid.stage.DesktopStage`; `build_exe.bat` then wraps it into a native launcher using the bundled `launch4j/` toolchain, optionally appends an encrypted project payload (NEOCAT01 footer + AES-GCM) via `embed_payload.ps1`, and stages the final `NeoCatroid.exe` plus a bundled minimal JRE (built by `jlink`).
