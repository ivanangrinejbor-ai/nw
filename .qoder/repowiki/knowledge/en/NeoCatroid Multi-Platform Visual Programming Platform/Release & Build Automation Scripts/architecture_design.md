Two flat script directories with no shared library — each file is a standalone CLI tool invoked directly from CI or by maintainers.
- `automationScripts/` (Python): `increaseVersionByOne.py` edits `../catroid/build.gradle` in-place to increment the `versionName`; `createBetaTestingPocketCodeAPK.py` orchestrates a full beta build by backing up `build.gradle` and `AndroidManifest.xml`, swapping app id / build type, invoking `./gradlew assembleDebug`, copying both debug APK outputs into the script directory with timestamps, then restoring the originals. All state mutation targets sibling `../catroid/` paths.
- `buildScripts/` (POSIX shell + rules): `checkUrlExists.sh` wraps `curl` with retry/backoff logic and maps HTTP 528 (invalid upload) to exit code 200 so Jenkins interprets it as UNSTABLE; `log_parser_rules` is a plain-text rule set consumed by the LogParser plugin to mark builds erroneous on instrumentation/ddmlib/Cobertura errors.
Dependency direction is one-way outward: scripts read/write files under `../catroid/` but have no imports between themselves.
